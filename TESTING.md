## 🛠️ Detailed Test Plan & Cases

### 1. Chat & Model Intelligence
**Objective:** Ensure high-fidelity LLM interactions and accurate model recommendations.
- **Positive**: Verified `chat_completion` round-trip and `chat_with_preset` system prompt application.
- **Negative**: Confirmed handling of invalid model IDs and empty prompts.
- **Results**: Successfully validated reasoning extraction (think blocks) and dynamic model routing.

### 2. Models & Session Management
**Objective:** Validate real-time metadata retrieval and usage tracking.
- **Positive**: Verified `list_models` parsing and token/cost incrementing in `get_session_usage`.
- **Infrastructure**: Confirmed pricing cache handles multiple currencies and pricing per million tokens.

### 3. Account Management
**Objective:** Validate billing transparency and key security.
- **Cases**: Verified credit balance retrieval and API key metadata (labels/limits) reporting.

### 4. Vision Capabilities
**Objective:** Ensure multimodal input processing.
- **Verified**: Base64 encoding for local files and direct analysis for remote URLs. Confirmed support for various image formats.

### 5. Semantic Memory (Context Store)
**Objective:** Validate persistent storage and retrieval across sessions.
- **Integration**: Verified that `pin_context` data persists in `context_store.json` across server restarts.
- **Search**: Confirmed cosine similarity retrieval with `top_k` filtering.

### 6. Code Intelligence & Analysis
**Objective:** Validate static and semantic analysis of local codebases.
- **Indexing**: Verified symbol extraction for functions, classes, and variables.
- **Search**: Confirmed cross-project symbol lookup and semantic code chunk retrieval.
- **Dependencies**: Validated NPM and Cargo dependency graph generation with version conflict detection.

### 7. Budget & Rate Limiting (Infrastructure)
**Objective:** Prevent cost overruns and manage API throughput.
- **Budget**: Confirmed that the server blocks requests *before* the API call if the budget is exceeded.
- **Resilience**: Verified circuit breaker opens after 3 failures and token buckets enforce requests per minute.

### 8. Security & Authentication
**Objective:** Protect sensitive credentials and data.
- **Isolation**: Confirmed API keys are never exposed in logs or outputs.
- **Sanitization**: Verified that `validatePath` blocks access to sensitive directories (e.g., `~/.ssh`).

### 9. Performance & Reliability
**Objective:** Ensure responsiveness under load.
- **Concurrency**: Verified stability during 5+ simultaneous chat requests.
- **Efficiency**: Confirmed cold-start time for model listing is `< 500ms`.
